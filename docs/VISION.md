# رؤية المنصة — Platform Vision

منصة SaaS مخصصة لمكاتب العقار التقليدية، بواجهة استخدام بسيطة جدًا عبر واتساب فقط، مع بنية تقنية تسمح بالنمو إلى شبكة عقارية مركزية.

## 1) نموذج العمل (SaaS)

- اشتراك مدفوع للمكاتب العقارية.
- فترة تجريبية مجانية لمدة **3 أشهر** لتسهيل تبني المنصة وبناء الثقة.
- الهدف الاستراتيجي: بناء شبكة بيانات عقارية مركزية (عقارات + عملاء) على مستوى المنصة.

## 2) قاعدة بيانات مركزية موحدة (Single DB, Multi-Tenancy)

- اعتماد قاعدة بيانات مركزية واحدة للمنصة (مثل PostgreSQL عبر Supabase).
- كل سجل عقار/عميل يجب أن يحتوي على `office_id` لتحديد المكتب المالك للبيانات.
- عزل كامل للبيانات بين المكاتب:
  - كل مكتب يرى بياناته فقط.
  - لا يمكن لأي مكتب الوصول لبيانات مكتب آخر.
- صلاحية **Super Admin**:
  - رؤية شاملة لجميع بيانات المكاتب.
  - إمكانية التجميع والتحليل عبر لوحة تحكم مركزية.

## 3) تجربة الاستخدام (WhatsApp-First)

- لا توجد لوحات تحكم معقدة لصاحب المكتب.
- واجهة الاستخدام الأساسية: محادثة واتساب طبيعية مع البوت.
- إدخال العقار يتم عبر إرسال:
  - صور العقار
  - فيديو قصير (اختياري)
  - السعر
  - الحي
  - الموقع الجغرافي (Location Pin)

## 4) الهيكلة التقنية والسحابة

- التكامل الرسمي عبر **WhatsApp Cloud API** (Meta) للاستقرار وتقليل مخاطر الحظر.
- تشغيل الـ Backend (مثل NestJS) على **Railway** لضمان العمل 24/7.
- الربط مع تيك توك عبر **OAuth** (مرة واحدة).
- استخدام نهج **Smart Copy-Paste** لمنصة حراج بدل الأتمتة العدوانية لحماية الحسابات.

## 5) الأتمتة الذكية وإدارة العملاء (Leads & Broadcasting)

- تصنيف العملاء الجدد تلقائيًا عبر ردود سريعة (Quick Replies).
- تسجيل العملاء المحتملين (Leads) مباشرة في قاعدة البيانات.
- إرسال موجه حسب الاهتمام والزمن (مثل من بحث خلال آخر أسبوع/شهر).
- حماية الرقم عبر سياسات منع الإزعاج:
  - منع تكرار إرسال نفس العقار لنفس العميل (Deduplication).
  - عدم إرسال أكثر من إعلان واحد يوميًا لنفس العميل.
  - إرسال “آخر الموجود” تلقائيًا للعملاء الجدد.
